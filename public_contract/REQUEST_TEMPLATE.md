# Real2Sim 任务提交模板

填写以下内容，并附上本次允许处理的原始资料。不了解的选项可以保留默认值或填写“未知”。

```text
【任务名称】
[自定义名称；不填则由执行端分配任务编号]

【原始资料】
输入类型：[单张照片 / 同一房间的多张照片 / 同一房间的视频]
素材：[附件名称，或当前接入渠道可访问且已授权的位置]
来源说明：[本人拍摄 / 经许可获得 / 可核实的公开实拍来源]
允许处理的范围：[全部所列素材，或明确限定的文件/时间段]
如果涉及多个房间，请分别列出分组，不默认合并。

【用途】
[静态拟真展示（默认）/ 机器人或物理仿真 / 方法对照实验]

【重建策略】
[独立建模 A（默认）/ 准确同款资产辅助 B / A+B 对照]
A 也可以查询家具规格；B 额外允许使用已核实的准确同款三维资产。
没有可核实同款资产时，B 的对应物体回退到独立建模。

【重点与限制】
重点匹配的物体/区域：[不填则默认主要可见结构和家具]
必须保留或禁止改动的内容：[例如家具摆放、门窗位置]
允许合理推断的内容：[例如不可见背面、未见墙段；也可填“按流程记录假设”]

【尺寸资料，可选】
用于帮助建模的尺寸：[对象 + 数值 + 单位 + 测量/目录来源；没有则填未知]
独立验收资料：[如有，请单独标记并与建模输入隔离；没有则填无]
未明确标为独立验收的尺寸默认作为建模参考，不作为后续真值评分。

【可选运动与形变，默认全部关闭】
铰链：[关闭 / 开启]；目标：[柜门、房门等具体部件，或由 Agent 判断适用对象]
布料：[关闭 / 开启]；目标：[窗帘、毯子、衣物等]
体积柔体：[关闭 / 开启]；目标：[需要压缩形变的软垫等]
关闭动态功能仍应完成合理的静态软包形态和褶皱。

【期望交付】
[可编辑 Blender 场景与预览（默认）]
额外格式：[GLB / USD / MuJoCo / 由执行端说明可支持格式]
额外演示：[多视角 / 动态相机 / 关节运动 / 布料或柔体演示]

【其他约束，可选】
[项目约定的时间、资源、文件体积或精度要求；不确定可留空]
```

独立验收资料若不能在执行环境中有效隔离，本次只能进行建模一致性与可视化检查，不能声称完成独立盲验。
