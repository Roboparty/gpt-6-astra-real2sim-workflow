# Real2Sim 外部使用资料包

Real2Sim 将实拍室内照片、多视图照片或视频，重建为可编辑三维场景，并按需要生成仿真文件。

| 读者 | 文件 | 用途 |
|---|---|---|
| 使用者 | [使用说明](USER_GUIDE.md) | 了解如何提交资料、流程如何推进、会收到什么 |
| 使用者 | [任务填写模板](REQUEST_TEMPLATE.md) | 填写本次输入、用途、重点与可选功能 |
| 使用者或执行 Agent | [完整任务 Prompt](MASTER_PROMPT.md) | 一份不依赖历史上下文、包含完整工作流的任务说明 |
| 执行 Agent / 集成人员 | [执行规范](AGENT_EXECUTION_SPEC.md) | 阶段输入输出、质量门槛、回退、记录与工具边界 |
| 使用者 / 服务部署方 | [能力与边界](CAPABILITIES.md) | 区分已实现机制、实际验收范围和需要另行部署的服务功能 |

建议使用方式：使用者阅读说明并填写任务模板；执行端把已填写内容与完整 Prompt 一起交给具备相应工具的 Agent。使用者不需要填写脚本路径、GPU 编号或内部阶段文件。

本资料包是面向外部使用的工作流与任务合同，配套实现采用 `quality_v2`。它不表示网站上传、用户账户、任务队列或下载托管服务已经部署完成。
