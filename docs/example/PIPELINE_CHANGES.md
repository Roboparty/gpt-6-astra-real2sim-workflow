# 生成与验收链路修订

本次不是只修改三件家具的坐标。保留通用 18 阶段框架，增加以下实际执行约束；原有“走完流程即结构正确”的解释已撤销。

| 环节 | 旧缺口 | 本版实现 |
|---|---|---|
| 观察 → 模型 | 对象外轮廓与笼统关系未绑定建模 | 部件观察文件含来源哈希、归属、可见性、源图点与结构约束；构建器实际读取并验证 |
| 家具生成 | 面、靠背、脚点独立反投影，后续平均脚点 | 整件局部坐标、共享尺寸、刚性姿态拟合；图像点不能直接替代结构 |
| 结构合同 | 只查单位、正尺寸、ID、房间/灯 | `scene.structure` 记录真实对象、唯一部件归属、连通接头图、锚点和支撑 |
| 几何执行 | 缺少实际可见家具的专门检查 | Blender 求值网格接头/落地/相交筛查，逐部件对应点重测与重投影 |
| 视觉审核 | pass 字段与非空 evidence 即可，未保证覆盖/版本 | 精确覆盖当前语义对象；证据必须在当前工件中；冻结模型哈希与当前版本一致；审计必须与执行器产物字节一致 |
| 局部与全局 | 相机点误差、全图亮度容易被误当家具合格 | 局部原图/渲染、单件三向、组合三向独立必查；最终着色后再查局部 |
| 静态与动力学 | 代理碰撞/短时仿真通过易被过度解释 | 可见网格结构单独验收，动力学仅报告其代理、材料先验和实际试验范围 |
| 运行来源 | 相对模块路径在子进程工作目录下可解析到其他安装 | `core.execute` 固定当前快照的绝对模块路径，worker 记录实际代码哈希 |
| 再执行 | 旧报告可被误认为仍有效 | 正式 revise、指纹依赖失效、新尝试目录、旧证据留存；无直接写成功状态 |

主要通用实现位于 `workflow/r2s/{structure.py,quality.py,contracts.py,core.py,stage_worker.py,blender_structure.py}`，对应阶段 Prompt 一并更新。`case/{furniture_observation.json,fit_furniture.py,furniture_model.py}` 是本照片的观察、参数拟合和建模实现，不能当成任意新照片的自动模型。

构建脚本中的旧版本分支仅保留作历史复现；新版配方和当前候选显式使用版本 4。缺少新结构合同的旧分支不能通过当前 quality_v2 验收，旧脚点平均逻辑不在新版执行路径中。

真实网格错误注入共六种情形：正常接触通过，断腿、错横档、桌椅穿插、错归属、结构整体移位却沿用旧源图点均失败。合同回归共八项，包含正常结构及七类拒绝情况。完整失败理由见 `evidence/mesh_mutation_tests.json`、`evidence/contract_tests.json`。

检查有边界：网格相交采用候选三角形与内部采样，不是精确布尔体积或任意复杂网格的数学证明；目前适合这些闭合构件。人工审核仍要判断形状、归属、连接方案及真实遮挡是否合理。隐藏部件的合理补全也不能替代实拍/测量真值。
