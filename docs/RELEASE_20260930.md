# Verified generation integration — 2026-09-30

This version consolidates the research and generation-skills branches into the
formal main line. It is the currently validated integration, **not a claim of
global optimality, accepted real-room reconstruction or SOTA**.

## Selected configuration

- Native `quality_v2` executes RoomKit construction, optional Pi3X reference
  consumption/status, and local geometry/appearance feedback inside its existing
  review and revision workflow. [Usage](GENERATION_SKILLS.md).
- Blender remains the authoritative editable representation. Export checks
  independently compare the three file formats with the original scene; invalid
  worker output, stale references and changed files cannot be manually accepted.
- Camera/geometry/material uncertainty remains explicit. Hinges, cloth and soft
  bodies are optional and off unless requested. Pi3X installation/inference does
  not start automatically, and its spent preparation budget is preserved.
- The imported-floor normal-link removal remains an explicit research diagnostic,
  not a default material repair: it improves USD in the tested scene but worsens
  GLB. No per-format or per-region best-of model was assembled for this release.

## Final verification

All **14/14 runner groups passed** on the existing remote CPU runtime, with
**61.319100 seconds** of measured group wall time. Python source bytes in the
release working tree match the tested snapshot. Tests include the native
generation-to-review path, skill contracts, required-reference and shared-budget
guards, Pi3X receipt binding, RoomKit canonical export with actual MuJoCo probes,
empty/single assemblies, geometry/physics/refinement regressions, immutable
annotation additions and native source-bound interchange gates.

These engineering tests include explicit synthetic fixtures and replayed export
files. They are not independent reconstruction accuracy or new robot-task
qualification. [Final runner evidence](research/evidence/final_release_20260930/validation_summary.json)
and [source manifest](research/evidence/final_release_20260930/source_manifest.json).

## Retained material ablation

One registered binary change disconnects only the imported floor material's
Principled Normal input, preserving other material fields, geometry and the exact
source camera/light/World rig. The original control renders are hash-bound.

| Format | Photo full-image MAE, control | Normal link removed |
|---|---:|---:|
| GLB | 0.140484 | **0.174770 — worse** |
| USD | 0.137857 | **0.106795 — better** |

Native repeat MAE is 0.082987. USD's floor-region error improves, but its vent
region worsens; GLB's full-image and floor-region errors both worsen. The mixed
result rejects a universal normal-disconnection repair. The original GLB
all-vertex geometry failure also remains; its nonsurface-vertex explanation is
recorded separately and did not change the gate.

## Known limits and preserved history

Portable appearance is not equivalent to native Blender on the retained detailed
room. Geometry AABBs are not full-surface proofs. The three-video common camera/
editable-model benchmark remains incomplete; TUM RGB-D inputs are still 0/3 ready.
No new GPU hours, paid API requests, camera trials or dependency-budget reset was
introduced by this release. The frozen `f0e61696` baseline, historical failures,
all scene versions and previous branches remain in history.

See [known limitations](../KNOWN_LIMITATIONS.md) and the ongoing
[research state](research/STATE.json). Subsequent experimental changes remain on
the research branch unless separately authorized for formal publication.
