# 整体外观、纹理范围与固定视角验证

2026-09-26。此修订改变通用工作流与验收，不修改已有卧室模型、历史结论或首页 V5 预览。新的完整实拍重建单独执行；以下结果仅为协议、实际 Blender 着色器和执行器集成测试，不代表新场景已经达到 V5 质量。

## 已实现

- **整体先于局部**：观察覆盖建筑围护、开口、家具、软物体、反射面、灯具、外景。每个类别列目标或明确说明不存在，每个目标记录完整可见范围、整体配色、图案分布、方向与尺度依据。
- **局部来源与应用范围分开**：照片小样本默认为局部；扩展到整物体或平铺需要原图中至少两个不重叠的重复区域及解释。完整物体的原图映射可声明完整来源，但采样范围必须覆盖接受的整物体裁图。允许整体一致且标明推断的生成／程序／授权纹理。
- **实际材质检查**：材质记录绑定实际对象和材质槽，检查 PBR 参数、坐标来源、图像重复方式及求值后的 UV。软表面贴图必须跟随 UV；混合家具的木架和布料分别声明。纯介电材质不能通过金属度补反光。遗漏实际可见材质也会被检测。
- **材质与光照分离**：build_render 独立读取已接受的材质阶段模型，比较当前着色器和分配，发现光照阶段修改材质则阻断最终通过。执行器生成完整场景中性光图，最终材料／光照检查必须实际引用。
- **持续防退化**：第一次真实构建保留三个固定相机及分辨率、色彩变换、曝光、帧和采样设置。后续相机／房间／观察修订仍渲染这些视角，另保留当前拟合视角与适应性诊断图。前后审核必须涵盖三个固定视角，最佳候选和停滞计数不能被重新建基线绕过。退化候选保持拒绝，选定引用仍指向最佳候选；不覆盖历史模型，也不偷偷替换依赖文件。
- **全景验收**：整体构图、材质光照一致性、纹理范围、软物体形状分别判定。明显全景差异不能仅写成局限后通过；每个对象还需说明整物体外观及其与场景的关系。

同时修正诊断相机选位：不再把房间围护面当作家具目标参与家具可见比例与避障检查；所有围护结构仍保留在实际渲染中。

## 实际验证

使用现有 Linux Python 3.10 环境、Blender 4.5.3 LTS，CPU 2 线程执行小型测试；未安装或转移大依赖、未修改历史房间。

| 测试 | 验证范围 |
|---|---|
| `test_appearance_contract.py` | 场景类别漏项、局部裁图冒充整体、无证据平铺／扩展、重复证据裁图重叠、缺少 UV 声明、完整来源边界、重标定保留最佳候选／固定协议／停滞计数、三视角覆盖、实际审计失败不能通过 |
| `test_blender_appearance.py` | 真正读取材质节点；拒绝世界坐标布料、局部／整物体图片误设 REPEAT、介电材质设高金属度、塌缩 UV、遗漏材质及光照修改材质；改变源相机／曝光／房间元数据后固定视角像素一致 |
| `test_appearance_worker.py` | 用独立构造的小封闭房间运行真正的 stage_worker → 元数据检查 → 材质基准读取 → Blender 渲染 → 图像绑定；正常输入通过，篡改材质的光照模型产生失败审计，全景中性光和三视角均绑定当前模型 |
| `test_refinement.py` | 原有返工、依赖失效、预算、证据绑定和退化拒绝；显式 version 0 的旧比较行为仍可测试 |
| `test_surface_contract.py` | 13 项既有表面证据合同回归 |
| `test_structure_contract.py` | 8 项既有结构合同回归 |
| `test_evaluated_metadata.py` | 真实 Blender 下局部顶点、修改器、曲线和隐藏对象的几何元数据一致性 |

以上测试通过。固定渲染测试比较解码后的像素，而不要求包含渲染时间等元数据的 PNG 文件字节完全相同。

## 范围与迁移

完整字段与例子见 [appearance.md](../workflow/r2s/prompts/appearance.md)。refinement 默认 `appearance_contract_version: 1`，版本进入阶段指纹。无 refinement 的旧任务保持原行为；显式 version 0 只用于历史协议复现，不代表符合新要求。旧的局部四阶段测试入口显式保持 version 0，不能作为新完整场景验证。

当前着色器适配器要求一个活跃 Principled BSDF，复杂着色器组须先扩充适配与回归，不以不完整检查冒充支持。纹理坐标和 UV 存在性检查不能判定艺术图案是否正确，也不能量化所有 UV 拉伸或残余烘焙光照。重复区域是否真是同种图案、观察是否漏掉物体、全景是否更接近原图，仍由 Agent 对绑定的原图和真实渲染判断。有限测试不构成任意场景质量保证。

固定视角保持初始世界坐标；后续模型不能偷偷换原点／尺度。合法的新输入或新的世界坐标系统应另建案例。对看不见的结构明确保留假设，不把围护完整、程序通过或 ArtVIP 一致性说成实物精度。真实完整流程测试将在新案例中记录，既有卧室展示不是本修订的新输出。
