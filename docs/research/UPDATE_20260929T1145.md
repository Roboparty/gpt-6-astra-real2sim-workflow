# Three-source visible-object annotation freeze — 2026-09-29 11:45 UTC

A first shared annotation bundle is frozen for all three development videos.
It binds **18 original frame hashes, six persistent object identities and 36
frame/object observations**. There are 17 observed boxes and 19 out-of-frame
entries retained as null. This is sparse, model-authored development annotation,
not complete scene labeling, segmentation ground truth or a ready three-scene A/B.

## Fixed scope and actual coverage

The [protocol](ANNOTATION_PROTOCOL_20260929.json) was written before annotation.
Each internal agent inspected all six full-size display previews for one source
and selected two static objects visible in the first frame. Identities could not
be replaced when the camera turned away. The root agent then reviewed all three
overlay sheets; no correction pass was needed. Initial submissions remain intact.

The first-frame selection rule produces poor temporal coverage in two sources.
This is an observed limitation of this annotation design, not a reconstruction
failure or evidence that those videos lack useful geometry. The later kitchen
objects are not substituted into the original denominator. Future broader
inventory work needs a new explicit annotation version retaining this bundle.

Boxes cover the observed visible extent only. They may enclose background and
must not be converted into silhouette masks or used as independent geometry
truth. The assumed boundary uncertainty is ±10 pixels, not measured annotator
accuracy. Confidence labels are subjective. Reflection contents are not labeled
as separate physical objects; the vase label excludes flowers. All 18 frames
were used in earlier SfM and retain `development_fit` status.
