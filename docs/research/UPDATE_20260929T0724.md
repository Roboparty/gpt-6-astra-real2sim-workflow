## Single-assembly repair

`review_contract` previously required a nonempty `interassembly_checks` list even
for one furniture assembly. It now computes the exact expected cross-owner
component-pair set from the declared parts. One assembly correctly needs zero
cross-owner pairs; two or more must cover all pairs once with correct owners.
Duplicate, reversed-duplicate, missing, unknown and same-owner pairs are rejected.
Existing ownership, joints, floor, landmark, model hash and view checks remain.
