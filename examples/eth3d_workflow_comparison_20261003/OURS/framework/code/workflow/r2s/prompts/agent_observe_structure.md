# Part-level observation supplement

This supplement is mandatory for quality_v2 observation. Preserve source-image identity and give furniture_observation.json with named furniture owners, part inventory, structural constraints, source landmark IDs and pixel coordinates, visibility (observed/partial/unobserved), uncertainty and alternative interpretations. Define acceptance tolerances before fitting. Separate hidden-foot assumptions from visible-foot evidence. Explain occlusion without inventing connections between different furniture.

The modeller consumes this accepted artifact unchanged and binds its hash to the generated assembly and parameter fit. The observation artifact is not a script for arbitrary furniture; its contents must be re-authored after inspecting each new source. When no multipart furniture is applicable, record explicit reasons rather than inventing an assembly.
